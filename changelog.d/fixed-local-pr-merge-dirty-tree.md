- **Local PR merges no longer risk uncommitted work.** Merging a local pull request (or cherry-picking commits onto another branch) into the branch you're currently on could, if it hit a conflict, discard your uncommitted changes during rollback. These operations now refuse up front on a dirty working tree with a clear "commit or stash your changes first" message — matching the history-rewrite actions — and the Merge button explains why it's disabled. (Untracked files are still fine.)
